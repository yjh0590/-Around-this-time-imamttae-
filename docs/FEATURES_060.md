# 생활 기록 기능 · 0.6.0

## 반복 일정

오늘 또는 달력의 일정 추가에서 반복 방식과 종료일을 선택한다. 매일·매주·매월·매년을 지원하며 한 번에 최대 366개의 실제 날짜별 일정을 만든다. 종료일을 넘어 무기한으로 생성하지 않는다.

매월 31일은 없는 달에서 말일로 맞춘다. 이후 31일이 있는 달에는 다시 31일에 생성한다. 매년 2월 29일은 평년 2월 말일로 맞춘다. 각 날짜의 완료·수정은 독립적이다. 선택한 한 건 삭제와 반복 묶음 전체 삭제를 구분하며 전체 삭제는 추가 확인을 받는다.

이미 생성한 반복 묶음의 규칙을 한 번에 변경하거나 외부 ICS의 반복 규칙을 전개하는 기능은 아직 없다. 외부 반복 ICS는 기존처럼 제외 개수를 표시한다. 네이버 CalDAV의 반복 일정도 기존 제한을 유지한다.

## 월별 가계부

기록 화면에서 **가계부**를 선택하고 월을 바꾼다. 해당 월의 저장된 지출 합계·건수와 가장 큰 지출, 지난달·작년 같은 달의 합계를 보여준다. 목록도 선택 월로 제한한다. 비교 값은 앱에 저장한 지출만 합산한 것이며 실제 전체 계좌 소비를 의미하지 않는다.

원 단위 정수 금액을 BigInt로 합산해 큰 합계의 반올림 오차를 피한다. 금융 계정 연동·외화·수입·계좌 잔액 분석은 포함하지 않는다.

## 일기 가져오기

**기록 → 기록 연결 → 일기 가져오기**에서 UTF-8 CSV를 선택한다. 첫 줄은 `date,text`, 날짜는 YYYY-MM-DD, 글은 1,000자 이하, 파일은 2MB 이하·최대 5,000행이다.

```csv
date,text
2025-11-23,"가을 바람이 좋았다.
다시 걷고 싶은 길."
```

미리보기 후 적용한다. 같은 날짜·글·파일 내 등장 횟수로 식별하므로 재가져오기 시 중복되지 않는다. 가져온 파일 이름을 출처로 보존한다. 지원하지 않는 날짜·글은 파일 전체를 거부하며 기존 기록을 유지한다. 서비스별 로그인이나 고유 내보내기 형식을 자동 해석하지 않는다.

## 과거 날씨

**기록 → 그 무렵의 세상 → 그날의 날씨 찾기**에서 날짜와 당시 지역을 선택한다. 서울·부산·인천·대구·대전·광주·강릉·제주의 대표 좌표를 제공한다. 좌표는 도시를 대표하는 근사 위치이며 당시 사용자 위치를 추정하지 않는다.

조회 버튼을 눌렀을 때에만 선택한 날짜와 대표 좌표를 Open-Meteo로 전송한다. 계정 정보·일기·사진·은행 자료는 전송하지 않는다. 응답에서 최저·최고 기온(°C), 하루 강수량(mm)을 확인하고, 사용자가 저장 버튼을 눌러야 개인 기록에 추가한다. 같은 날짜·지역을 다시 저장하면 기존 편집 내용을 유지한다.

자료는 **Open-Meteo ERA5 재분석 데이터**이며 관측소의 실측 기록과 다르다. ERA5의 제공 지연을 고려해 1940년부터 7일 전까지 조회하도록 제한했다. 시간대는 Asia/Seoul로 지정한다. 현재 날씨·예보·자동 위치 감지·백그라운드 수집은 아니다.

서버는 고정 HTTPS 제공자만 호출하고 입력·응답 날짜·수치·단위를 검증한다. 응답 크기·대기 시간을 제한하며 같은 날짜·지역의 응답은 최대 24시간, 최대 200건 메모리 캐시에 보관한다. 화면에서 재분석 자료와 출처를 밝히고 저장 시 조회일도 남긴다.

- [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api)
- [이용 조건](https://open-meteo.com/en/terms): 현재 공개 무료 API는 비상업적 개발·개인 사용 범위다. 상업 출시 전 유료 이용 조건과 제공자 선택을 확인한다.
- 확인일: 2026-11-23.

## 백업과 검증

새 백업은 버전 3이다. 기존 버전 1·2 백업도 읽으며 반복 묶음 정보와 일기 출처를 보존한다. 구버전 앱은 버전 3을 지원하지 않는다. 저장 실패 시 새 반복 일정·일기·날씨 기록을 적용하지 않는다.

자동 테스트 31개와 Chrome 검증에서 월말·윤년·생성 개수 제한, 개별 완료·묶음 삭제, 반복 저장 실패 후 재시도, 일기 가져오기·중복, 월별 합계, 날씨 조회·저장, 이전 앱 흐름과 세 기종 미리보기를 확인했다. 브라우저 테스트의 날씨는 가상 응답이다. 별도로 실제 공개 API에 서울 대표 좌표·2025-11-23을 조회해 성공을 확인했다. 실제 네이버 계정 검증은 이번에도 수행하지 않았다.
