# 기록장 · 0.7.0

기록 기능이 부가 요소처럼 보이고 화면이 지나치게 정형적이라는 피드백을 반영했다. 날짜별 개인 기록장을 중심으로 다섯 기능을 직접 드러낸다.

## 화면 구성

- 제목: 기록장. 현재 연도와 이맘때를 작게 표시한다.
- 주요 메뉴: 일정·사진·가계부·일기·세상. 아이콘, 이름, 실제 저장된 기록 수를 함께 보여준다.
- 도구: 모아보기, 가져오기, 내용·날짜 검색.
- 본문: 왼쪽 날짜와 오른쪽 기록. 동일한 날의 항목을 묶는다.
- 일기: 세리프 글꼴과 문장 사이 여백. 날짜는 왼쪽에 있으므로 본문 위에서 중복 표시하지 않는다.
- 사진: 같은 날의 사진을 묶는다. 파일 이름은 본문 제목에서 줄이되 원래 값은 보존하고 사진 대체 텍스트·수정 화면에서 확인할 수 있다.
- 가계부: 제목과 금액을 한 행에 표시한다. 출처와 메모는 아래에 둔다.
- 세상: 출처가 있는 짧은 스크랩. 날씨 조회와 링크 남기기는 하단 도구에서 제공한다.
- 항목 메뉴: ‘···’를 열어 수정·삭제한다. 삭제 확인과 입력 검증은 기존과 같다.

장식용 문구와 반복되는 테두리·배지를 줄이고 흰색·회백색, 계절 강조색과 여백은 유지한다. 입력하지 않은 이야기를 자동으로 만들어 채우지 않는다.

## 확인 화면

- [기록이 있는 예시](device-records-demo.png): **격리된 브라우저 테스트의 가상 일기·지출**로 구성한 화면이다. 사용자 앱에 예시 데이터를 설치하지 않는다.
- [빈 기록장](device-records-empty.png): 실제 데이터가 없을 때 보여주는 화면이다.

<http://localhost:3000/preview#records>에서 현재 브라우저의 실제 기록장을 조작할 수 있다. 웹 기종 프레임이며 실기기 촬영 화면은 아니다.

## 보존한 기능

기록 종류 표시 설정, 검색, 가져오기와 백업, 사진 확대, 지출 요약, 출처 링크, 날짜별 묶기, 작성·수정·삭제와 저장 방식은 유지한다. 이번 변경은 데이터 스키마를 바꾸지 않는다.
