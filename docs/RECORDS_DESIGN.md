# 이맘때의 나 · 0.8.0

따뜻하게 지난 순간을 회상하는 경험을 앞에 둔다. 다섯 기록 메뉴 아래에서 실제 과거 사진과 그날 쓴 문장을 펼쳐보고, 해당 날짜의 전체 기록으로 이어진다.

## 회상 경험

- 작년 같은 날짜 전후 7일의 가장 가까운 날을 우선 펼친다. 없으면 가장 최근 과거 기록을 보여준다. 오늘·미래 기록은 아래 기록장에만 남긴다.
- 사진과 일기가 함께 있으면 사진 아래에 실제 일기 문장을 표시한다. 자동 감상문이나 요약을 만들지 않는다. 긴 글은 일부를 보여주고 ‘그날의 기록 보기’에서 전체를 읽는다.
- 화살표·좌우 방향키·가로 스와이프로 다른 날짜를 넘긴다. 짧은 이동과 페이드만 사용하며 자동 재생은 없다. 모션 줄이기를 지원한다.
- 표시 종류·종류 필터·기간을 반영한다. 검색할 때는 회상을 숨겨 결과에 집중한다.
- 빈 상태는 기존 계절 캐릭터와 가져오기 안내를 보여준다. 저장된 날짜·기록·테마는 바꾸지 않는다.

## 화면 구성

- 제목은 ‘이맘때의 나’로 두고 옆에 일기 쓰기 버튼을 둔다. 메뉴와 날짜는 기기 기본 글꼴, 일기 문장은 기기에 설치된 한글 명조 계열 글꼴을 쓴다.
- 회상 화면의 날짜와 글은 흰 바탕에 짙은 글자로 표시한다. ‘작년 이맘때’와 넘기기 버튼은 한 줄에 둔다.
- 주요 메뉴: 일정·사진·가계부·일기·세상. 아이콘, 이름, 실제 저장된 기록 수를 함께 보여준다.
- 회상 아래 도구: 남겨둔 기록, 가져오기, 내용·날짜 검색.
- 본문: 왼쪽 날짜와 오른쪽 기록. 동일한 날의 항목을 묶는다.
- 일기: 세리프 글꼴과 문장 사이 여백. 날짜는 왼쪽에 있으므로 본문 위에서 중복 표시하지 않는다.
- 사진: 같은 날의 사진을 묶는다. 파일 이름은 본문 제목에서 줄이되 원래 값은 보존하고 사진 대체 텍스트·수정 화면에서 확인할 수 있다.
- 가계부: 제목과 금액을 한 행에 표시한다. 출처와 메모는 아래에 둔다.
- 세상: 출처가 있는 짧은 스크랩. 날씨 조회와 링크 남기기는 하단 도구에서 제공한다.
- 항목 메뉴: ‘···’를 열어 수정·삭제한다. 삭제 확인과 입력 검증은 기존과 같다.

장식용 문구와 반복되는 테두리·배지를 줄이고 흰색·회백색, 계절 강조색과 여백은 유지한다. 입력하지 않은 이야기를 자동으로 만들어 채우지 않는다.

## 보존한 기능

기록 종류 표시 설정, 검색, 가져오기와 백업, 사진 확대, 지출 요약, 출처 링크, 날짜별 묶기, 작성·수정·삭제와 저장 방식은 유지한다. 이번 변경은 데이터 스키마를 바꾸지 않는다.
